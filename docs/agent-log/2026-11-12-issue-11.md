# Issue #11: Window too short: the enrollment password screen needs scrolling

- **Date:** 2026-11-12
- **Branch:** agent/11-window-fit
- **Action log:** `.claude/logs/2026-11-12.log` on the owner's computer (every step, with times)

## What was asked
The window is a fixed 460×760 and the enrollment password screen doesn't fit: Cancel is cut off at 150% scaling. Tighten the vertical spacing in `app.css` (not the shared `style.css`) so that screen fits without scrolling, and make the window resizable with a minimum size. The owner chose the resizable window over a fixed one.

## Plan (planner)
- **Spacing:** overrides in `app.css` only. Measured with the real fonts in a headless browser, the enrollment password screen with an error goes from 791 px to 715 px tall, in both languages.
- **Window:** WS_OVERLAPPEDWINDOW, which is resizable and can be maximized, with a WM_GETMINMAXINFO minimum of 400×560 logical, scaled for DPI and capped to the work area. The size calculations move to `internal/winui/geometry.go`, with unit tests. `show()` keeps a maximized window maximized.
- **Windows UI tests:** `scripts/test-ui.ps1` checks the new style and the minimum size. `scripts/ui/check-start.mjs` checks the screen at 460×760, with screenshots in Arabic and English.
- **Not covered:** a 1080p screen at 150% still scrolls; resizing covers it. `CHANGELOG.md` is left to the owner.

## What changed (implementer)
- `internal/winui/geometry.go` (new): `baseWidth`/`baseHeight`, `minWidth`/`minHeight` (400×560), `scale`, `minTrackSize` and `placement`, plus the `rect`/`point` types moved from `win32_windows.go`.
- `internal/winui/win32_windows.go`: `wsWindow` (WS_OVERLAPPEDWINDOW) replaces `wsFixedWindow`; adds `wmGetMinMaxInfo`, `minMaxInfo` and `pIsIconic`.
- `internal/winui/window_windows.go`:
  - The window is created with `wsWindow`.
  - New helpers `frame(dpi)` and `workArea(hwnd)`; `placeWindow` uses `placement()`.
  - WM_GETMINMAXINFO sets the minimum size.
  - `show()` restores only a minimized window, so a maximized one stays maximized.
- `internal/ui/web/assets/app.css`: tighter spacing; `style.css` is unchanged.
- `scripts/test-ui.ps1`: checks that the window is resizable and can be maximized, and that it doesn't go below the minimum size.
- `scripts/ui/check-start.mjs`: checks that the enrollment password screen fits 460×760 without scrolling, in English and Arabic, with screenshots 07 and 08.
- `docs/testing.md`: the test-ui row and a manual checklist line.
- Tests added or changed: `TestScale`, `TestMinTrackSize`, `TestPlacement` (`internal/winui/geometry_test.go`).
