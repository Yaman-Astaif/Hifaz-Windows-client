# Agent work reports

One file per issue that Claude Code worked on, named
`YYYY-MM-DD-issue-N.md` and made from [TEMPLATE.md](TEMPLATE.md). Each says
what was asked, the plan, what changed, the checks, what the review found and
what is left open. The same text is the description of the pull request.

The step-by-step action log (every file read or edited, every command, every
agent started and finished, anything blocked) is kept on the computer where
Claude Code runs, in `.claude/logs/YYYY-MM-DD.log`, and is not committed.
